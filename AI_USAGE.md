# AI Usage Disclosure

## Purpose
AI tools were used as supporting assistants during the development of the FinTrust 360 data analytics capstone project.

## Areas Where AI Assistance Was Used
- Project planning and organization of the analytics workflow.
- Assistance with Python scripts for data preparation and CSV export.
- Assistance in structuring and reviewing SQL analysis queries.
- Dashboard layout and presentation ideas.
- Assistance with drafting project documentation and explaining analytical findings.

## Human Review and Validation
- The original and cleaned datasets were retained as separate files.
- The cleaned data was exported and imported into SQLite.
- All 11 SQL queries were executed against the project database.
- Query outputs were saved in an Excel workbook.
- Dashboard KPI values were checked against the SQL analysis results.
- Project files and outputs were reviewed before submission.

## Tools
AI-based assistance was used for guidance, drafting, troubleshooting, and dashboard development.

## Declaration
AI was used as a supporting tool. The project outputs were reviewed and validated by the project author. AI-generated content was not treated as automatically correct.
